# Countries Web Scraper

A Python + Selenium scraper that extracts country data (name, capital, 
population, area) from a practice website — demonstrating dynamic 
site scraping with browser automation.

## Features
- Scrapes 250 countries with structured data
- Uses Selenium for browser automation
- Clean CSV export with Pandas

## Tech Stack
Python, Selenium, BeautifulSoup, Pandas

## Output
Delivers a clean CSV file with 250 rows containing Name, Capital, Population, and Area.
